## 一、可行性结论

| 维度 | 评估 | 说明 |
|------|:----:|------|
| **GPIO 引脚** | ✅ 可行 | 仍有 GPIO 38-40、42-48 等多个引脚空闲 |
| **LEDC PWM 通道** | ✅ 可行 | ESP32-S3 共 8 通道，当前最多用 7（含水弹），剩余 1 通道 |
| **PS2 按键** | ✅ 可行 | 方向键 D-Up / D-Down 未被任何功能占用 |
| **代码复杂度** | ✅ 低 | 单舵机抬放仅需约 30 行代码 |
| **供电** | ⚠️ 需注意 | 舵机峰值电流大，TB6612 D153C 5V 输出可能不足，见第五节 |
| **机械结构** | ✅ 可行 | 1 个标准舵机 + 简单铝合金支架即可实现 |

**结论：完全可以加装，核心风险在于供电，建议单独增加一路 UBEC。**

## 三、机械方案选择

### 方案 A：单舵机摆臂（推荐）

```
        ┌──── 固定支架（固定在机器人车体）
        │
    [MG996R]  ← 舵机安装在支架上
        │
      ──┼──────── 铝合金臂（长 10–15cm）
                  └── 末端可装橡皮/海绵铲斗
```

- **自由度**：1 DOF（绕舵机轴旋转，等效抬起/放下）
- **动作范围**：实际使用 **0°（放下）↔ 90°（抬起）**，舵机物理极限 180°（留有调整余量）
- **优点**：结构最简单，1 个舵机即可，安装快；180° 规格可在支架安装角度偏差时通过代码校准补偿

### 方案 B：双舵机剪刀臂（扩展）

- 增加一个舵机做肘关节，实现更大的竖直行程
- 需额外 1 个 GPIO（GPIO 39）和 1 个 LEDC 通道
- 超出"简单抬放"需求，**不在本文重点范围**

| 编号 | 硬件 | 规格/型号 | 数量 | 参考价格（RMB） |
|:----:|------|----------|:----:|:--------------:|

| 2 | 舵机支架 | 铝合金多功能舵机支架（U 型或 L 型） | 1 | ¥5–10 |
| 3 | 机械臂连杆 | 铝合金 U 形连杆或铝型材（长 10–15cm） | 1 | ¥5–15 |
| 4 | 末端铲斗/夹板 | 3D 打印或 ABS 塑料板 | 1 | ¥0–10 |
| 5 | 5V/3A UBEC | 降压模块（输入 6–25V，输出 5V/3A）| 1 | ¥10–20 |
| 6 | 安装螺丝/铜柱 | M3 螺丝、螺母、铜柱 | 若干 | ¥3–5 |
| 7 | 杜邦线 | 3pin 15cm 延长线 | 1 | ¥1–3 |

**估算总费用：¥39 – ¥88 RMB**（不含已有电池/机架）

> 为什么选 **MG996R 标准180度** 而不是 SG90 或 MG996R 标准90度？
> - 臂长 12cm、末端含铲斗约 80g，所需扭矩 = 80g × 12cm = **960 g·cm**
> - SG90 额定 **180 g·cm** → **扭矩不足**，容易堵转损坏
> - MG996R 标准90度 → 扭矩够用，但物理行程仅 90°，支架安装角度稍有偏差就无法校准
> - **MG996R 标准180度** → 扭矩满足，物理行程 180°，代码中仍只用 0°–90° 区间，剩余行程作为安装误差缓冲，灵活性最好

## 五、供电评估（关键风险）

### 5.1 各模块 5V 电流汇总

| 模块 | 典型电流 | 峰值电流 |
|------|---------|---------|
| ESP32-S3（主控） | 150mA | 350mA |
| 激光发射器 | 30mA | 50mA |
| WS2812B × 8 颗 | 30mA（绿色低亮） | 300mA（全白全亮） |
| VS1838B | 5mA | 5mA |
| 水弹飞轮 × 2（如安装） | 600mA | 1200mA |
| 水弹拨弹舵机（如安装） | 100mA | 300mA |
| **机械臂 MG996R（新增）** | **350mA** | **2500mA（堵转）** |
| **5V 合计（含水弹）** | **~1270mA** | **~4700mA** |
| **5V 合计（仅机械臂，无水弹）** | **~670mA** | **~3500mA** |

### 5.2 TB6612 D153C 5V 输出限制

> TB6612 D153C 板载 5V 稳压器通常额定 **1.5–2A**，满足不了机械臂 + 飞轮电机的峰值需求。

### 5.3 推荐供电方案

```
7.4V 2S 锂电池（2000mAh，20C 放电）
      │
      ├──→ TB6612 D153C Vin+
      │         └─ 5V 输出（≤2A）→ ESP32、WS2812B、激光发射器
      │
      └──→ UBEC 5V/3A（新增）
                └─ 5V/3A 输出 → MG996R 舵机
                                  + 水弹飞轮电机（如安装）
                                  + 水弹拨弹舵机（如安装）
```

> **关键原则**：所有模块共地（GND 全部相连），但 5V 供电分两路，互不干扰。

## 六、电气接线

### 6.1 MG996R 舵机接线

| MG996R 引脚 | 线色 | 连接至 | 说明 |
|------------|------|--------|------|
| VCC | 红 | UBEC 5V 输出 | 舵机专用供电（3A UBEC）|
| GND | 黑 / 棕 | GND（与 ESP32 共地）| — |
| Signal | 橙 / 黄 | ESP32 **GPIO 38** | 50Hz PWM，脉宽 500–2500µs |

### 6.2 接线总图

```
7.4V 锂电池
  (+) ─────────┬──────────── TB6612 D153C Vin+
               │
               └──────────── UBEC 输入 Vin+（5V/3A）
  (-) ─────────┴──────────── GND（所有模块共地）

UBEC 5V 输出 ────────────── MG996R VCC（红）
                              水弹飞轮模块 VCC（如安装）
                              水弹拨弹舵机 VCC（如安装）

ESP32-S3 N8R2
  GPIO 38 ──────────────── MG996R Signal（橙）
  GND     ──────────────── MG996R GND（黑）
  GND     ──────────────── UBEC GND（共地）
```

### 6.3 舵机角度与 PWM 脉宽对应（标准180度规格）

| 动作 | 舵机角度 | PWM 脉宽 | 16bit 计数值（50Hz）| 备注 |
|------|---------|---------|:------------------:|------|
| 完全放下（水平）| 0° | 500µs | 1638 | `ARM_DOWN` 默认值 |
| — | 45° | 1000µs | 3277 | — |
| 完全抬起（竖直）| 90° | 1500µs | 4915 | `ARM_UP` 默认值 |
| — | 135° | 2000µs | 6554 | 安装偏差补偿区间 |
| 物理极限 | 180° | 2500µs | 8192 | 不建议长期使用 |

> - **代码默认使用 0°（1638）↔ 90°（4915）区间**，安装后如发现角度偏差，可将 `ARM_DOWN` / `ARM_UP` 在上表范围内调整。
> - 180° 规格确保即使支架安装偏 ±30°，仍有足够脉宽余量校准到理想位置。

## 八、PS2 手柄控制映射

### 8.1 BTN1 字节（ps2_data[3]）位定义

```
BTN1 字节：[□][×][○][△][R1][L1][R2][L2]   ← BTN2（已有定义）
BTN2 字节：[Select][L3][R3][Start][↑][→][↓][←]  ← BTN1
```

> 注意：固件中 `PS2_IDX_BTN1 = 3`（方向键字节），`PS2_IDX_BTN2 = 4`（动作键字节）

| 按键 | BTN1 掩码 | 操作方式 | 功能 |
|------|:---------:|---------|------|
| **D-Up（↑）** | `0x10` | 按住 | 机械臂持续抬起 |
| **D-Down（↓）** | `0x40` | 按住 | 机械臂持续放下 |
| **D-Up 松开** | — | 松开 | 停在当前角度 |
| **D-Down 松开** | — | 松开 | 停在当前角度 |

> D-Up / D-Down 方向键当前在固件中**未被任何功能使用**，无冲突。

### 8.2 已占用按键一览（供参考）

| 按键 | 所在字节 | 掩码 | 功能 |
|------|---------|:----:|------|
| L2 | BTN2 | 0x01 | 激光发射（短按/长按） |
| R2 | BTN2 | 0x02 | WS2812B LED 重置为绿色 |
| R1（建议）| BTN2 | 0x08 | 飞轮预热（水弹，如安装） |
| ○（建议）| BTN2 | 0x20 | 拨弹发射（水弹，如安装） |
| **↑ / ↓** | **BTN1** | **0x10 / 0x40** | **机械臂抬起 / 放下（新增）** |

## 九、代码修改说明

在 `esp32_robot_controller.ino` 中追加以下内容（Arduino-ESP32 **v3.x** API）：

### 9.1 宏定义

```cpp
// === 机械臂 ===
#define PIN_ARM         38    // 机械臂舵机 Signal

#define ARM_FREQ        50    // 舵机标准频率 50Hz（周期 20ms）
#define ARM_RES         16    // 16bit 分辨率（0–65535）
// 50Hz + 16bit：1计数 ≈ 0.305µs（20ms / 65535）
#define ARM_DOWN        1638  // 放下位置：500µs = 0°
#define ARM_UP          4915  // 抬起位置：1500µs = 90°
#define ARM_STEP        80    // 每次 loop 移动步长（越大越快）

// BTN1 方向键掩码（Active LOW）
// BTN1 字节 = ps2_buf[PS2_IDX_BTN1]
static constexpr uint8_t BTN_DPAD_UP   = 0x10;
static constexpr uint8_t BTN_DPAD_DOWN = 0x40;
```

### 9.2 全局变量

```cpp
// 机械臂当前 PWM 位置
uint16_t arm_pos = ARM_DOWN;  // 初始为放下
```

### 9.3 setup() 初始化

```cpp
// 机械臂舵机初始化
ledcAttach(PIN_ARM, ARM_FREQ, ARM_RES);
ledcWrite(PIN_ARM, arm_pos);
Serial.println("[ARM] Servo initialized (DOWN)");
```

### 9.4 loop() 控制逻辑

```cpp
// --- 机械臂控制（方向键 ↑ / ↓）---
const uint8_t btn1 = ps2_buf[PS2_IDX_BTN1];  // Active LOW

bool dpad_up   = !(btn1 & BTN_DPAD_UP);
bool dpad_down = !(btn1 & BTN_DPAD_DOWN);

if (dpad_up && arm_pos < ARM_UP) {
    arm_pos = min((uint16_t)(arm_pos + ARM_STEP), (uint16_t)ARM_UP);
    ledcWrite(PIN_ARM, arm_pos);
}
if (dpad_down && arm_pos > ARM_DOWN) {
    arm_pos = max((uint16_t)(arm_pos - ARM_STEP), (uint16_t)ARM_DOWN);
    ledcWrite(PIN_ARM, arm_pos);
}
```

> `ARM_STEP = 80` 时，每次 loop 调用移动约 24µs 脉宽，对应约 4°；按住方向键时连续执行，速度由 loop 频率决定（通常 20–50ms/次）。可按需调大/调小 `ARM_STEP`。

## 十、注意事项

| 编号 | 注意事项 |
|:----:|---------|
| 1 | **单独供电**：MG996R 堵转电流约 2.5A，必须通过独立 UBEC（5V/3A）供电，不可直接使用 TB6612 D153C 5V 输出 |
| 2 | **共地**：UBEC 的 GND 必须与 ESP32 GND 相连，否则舵机信号电平基准不一致 |
| 3 | **角度校准**：`ARM_DOWN`（500µs）和 `ARM_UP`（1500µs）为初始估算值，实际安装后需根据支架方向微调 |
| 4 | **机械限位**：建议在支架上加装机械限位螺丝，防止舵机过转损坏齿轮 |
| 5 | **载重**：末端载重不超过 **600g**（臂长 10cm），否则即使 MG996R 也会持续堵转发热 |
| 6 | **LEDC 通道**：加装后 8 通道全部用满（含水弹方案）；若不安装水弹方案，仍有 3 通道空余 |
| 7 | **GPIO 38 安全性**：GPIO 38 在 ESP32-S3 上无特殊 strapping 功能，可安全用于 PWM 输出 |
