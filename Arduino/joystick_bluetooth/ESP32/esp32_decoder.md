## 三、供电电路

> ⚠️ **D153C 内置降压稳压电路**，直接将电池电压转换为 5V 和 3.3V 向外输出，无需额外降压模块。

```
18650 电池组（2节串联 标称 ~7.4V，满电 ~8.4V）
        │
        ├──[正极]──[D153C ON/OFF 拨动开关]──→ D153C 顶部端子 Vin+
        │                                           │
        │                               D153C 内置降压稳压电路
        │                                ├── 5V 输出  ──→ ESP32-S3 5V 引脚
        │                                ├── 3.3V 输出 ──→ YFRobot 2015 VCC（⚠️ 见注）
        │                                └── Vout+    ──→ 电池原始电压直通（备用）
        │
        └──[负极]──────────────────────→ D153C 顶部端子 -（共地 GND）

GND 汇流点：D153C Vin- = ESP32 GND = YFRobot 2015 GND = 电机地（全部短接）
```

> ⚠️ **电平兼容说明**：
> - ESP32-S3 GPIO 为 3.3V 逻辑，**不耐 5V**
> - YFRobot 2015 解码器如以 **5V 供电**，其 DAT 输出将为 5V 电平，可能损坏 ESP32-S3 GPIO
> - **推荐做法：将 YFRobot 2015 接 D153C 的 3.3V 输出（而非 5V）**，使所有 PS2 信号保持 3.3V 电平，与 ESP32-S3 直接兼容，无需电平转换

## 四、YFRobot 2015 解码器接口说明

```
┌─────────────────────────────────────────────────────────┐
│               YFRobot 2015 游戏手柄解码器                │
│                                                         │
│   ● GND  —— 电源地                                      │
│   ● VCC  —— 电源输入（接 3.3V，保持与 ESP32 同逻辑电平）│
│   ● CLK  —— PS2 时钟输入（由主机 ESP32 提供）           │
│   ● CS   —— 片选/注意信号（Active LOW，由主机拉低发起）  │
│   ● CMD  —— 命令数据线（主机→解码器，SPI MOSI）         │
│   ● DAT  —— 数据返回线（解码器→主机，SPI MISO）         │
│              （DAT 线需 10kΩ 上拉至 VCC）               │
│                                                         │
│   内部包含：蓝牙接收模块 + PS2 协议转换芯片             │
│   通信协议：PS2 SPI-like，约 250kHz，MSB-first          │
└─────────────────────────────────────────────────────────┘
```

### 引脚功能说明

| 引脚 | 方向（相对ESP32） | 功能 | 电平 |
|:----:|:----------------:|------|:----:|
| **VCC** | ESP32 → 解码器 | 电源输入 | **3.3V**（推荐，保持电平兼容） |
| **GND** | 共地 | 电源地 | 0V |
| **CLK** | ESP32 → 解码器 | PS2 时钟，通信时钟源由主机生成 | 3.3V |
| **CS** | ESP32 → 解码器 | 片选（Active LOW），低电平激活通信 | 3.3V |
| **CMD** | ESP32 → 解码器 | 命令/数据（MOSI 方向），主机发给解码器 | 3.3V |
| **DAT** | 解码器 → ESP32 | 数据返回（MISO 方向），解码器发给主机 | 3.3V（需10kΩ上拉到VCC） |

## 五、YFRobot 2015 → ESP32-S3 接线

### 接线对照表

| YFRobot 2015 引脚 | 方向 | ESP32-S3 N8R2 引脚 | 说明 |
|:-----------------:|:----:|:------------------:|------|
| **GND** | — | **GND**（任意 GND 针） | 共地，必须连接 |
| **VCC** | ← | **D153C 3.3V 输出** | ⚠️ 接 3.3V（不接 5V），保持信号电平兼容 |
| **CLK** | ← | **GPIO 16** | PS2 时钟，ESP32 输出 |
| **CS** | ← | **GPIO 15** | 片选，ESP32 输出（Active LOW） |
| **CMD** | ← | **GPIO 17** | 命令线，ESP32 输出 |
| **DAT** | → | **GPIO 18** | 数据返回，解码器输出；**DAT ↔ VCC 间接 10kΩ 上拉电阻** |

### 接线示意图

```
YFRobot 2015 解码器                    ESP32-S3 N8R2
┌──────────────┐                    ┌──────────────────┐
│              │                    │                  │
│  GND ────────────────────────────── GND（任意GND针）│
│  VCC ◄───────────────────────────── D153C 3.3V输出  │
│              │                    │                  │
│  CS  ◄─────────── GPIO 15 ──────── (J1 Pin8, 左侧)  │
│  CLK ◄─────────── GPIO 16 ──────── (J1 Pin9, 左侧)  │
│  CMD ◄─────────── GPIO 17 ──────── (J1 Pin10, 左侧) │
│  DAT ──────────── GPIO 18 ──────── (J1 Pin11, 左侧) │
│        ↑                           │                  │
└──────────────┘       DAT↔VCC 之间  └──────────────────┘
               接 10kΩ 上拉电阻（DAT 线接电阻一端，VCC 接电阻另一端）
```

## 十、左摇杆控制逻辑

> 所有控制功能均通过**左摇杆**实现，右摇杆及按键暂不使用。

### 10.1 PS2 摇杆轴坐标系

| 轴 | PS2 通道 | 最小值 | 中心值 | 最大值 | 说明 |
|:--:|:--------:|:------:|:------:|:------:|------|
| LX | 左摇杆X轴 | 0 | 128 | 255 | 0 = 最左，255 = 最右 |
| LY | 左摇杆Y轴 | 0 | 128 | 255 | 0 = 最上（前推），255 = 最下（后拉） |

### 10.2 摇杆区域划分（死区 + 8方向）

```
         LX轴（左→右）
         0          96   128   160          255
         ├───────────┼────┼─────┼────────────┤
    0    │  左后区域  │    前进   │  右后区域  │  ← LY = 0（最前推）
         │           │           │           │
   96    ├───────────┼────┼─────┼────────────┤
         │  原地左转  │  死区停止  │  原地右转  │
  128    │           │  （中心）  │           │ LY轴
  160    ├───────────┼────┼─────┼────────────┤  （上→下）
         │  左后区域  │    后退   │  右后区域  │
  255    │           │           │           │  ← LY = 255（最后拉）
         └───────────┴────┴─────┴────────────┘
```

### 10.3 动作判定规则

| 优先级 | 条件 | 动作 |
|:------:|------|------|
| 1 | LX ∈ [96, 160] 且 LY ∈ [96, 160] | **滑行停止**（双轴在死区） |
| 2 | LY < 96 且 LX ∈ [96, 160] | **前进**（前推，无转向） |
| 3 | LY > 160 且 LX ∈ [96, 160] | **后退**（后拉，无转向） |
| 4 | LX < 96 且 LY ∈ [96, 160] | **原地左转**（纯左，无前后） |
| 5 | LX > 160 且 LY ∈ [96, 160] | **原地右转**（纯右，无前后） |
| 6 | LY < 96 且 LX < 96 | **左前**（左弧线前进） |
| 7 | LY < 96 且 LX > 160 | **右前**（右弧线前进） |
| 8 | LY > 160 且 LX < 96 | **左后**（左弧线后退） |
| 9 | LY > 160 且 LX > 160 | **右后**（右弧线后退） |

> **死区说明**：中心区域 LX/LY ∈ [96, 160]（±32 死区）防止摇杆回弹误触发，实际死区大小可在代码中调整。

## 十一、电机控制真值表

> **定义**：
> - 电机 A = 左电机（接 AO1/AO2，由 AIN1/AIN2/PWMA 控制）
> - 电机 B = 右电机（接 BO1/BO2，由 BIN1/BIN2/PWMB 控制）
> - **STBY（GPIO 10）必须 HIGH 电机才能工作**；置 LOW 可紧急切断双路电机
> - PWM：255 = 全速，200 = 约 78% 速度，0 = 停止

| 动作 | 左电机（A） | AIN1 | AIN2 | PWMA | 右电机（B） | BIN1 | BIN2 | PWMB |
|:----:|:-----------:|:----:|:----:|:----:|:-----------:|:----:|:----:|:----:|
| **前进** | 正转 | HIGH | LOW | 255 | 正转 | HIGH | LOW | 255 |
| **后退** | 反转 | LOW | HIGH | 255 | 反转 | LOW | HIGH | 255 |
| **左前**（左弧线前进）| 停止 | LOW | LOW | 0 | 正转 | HIGH | LOW | 255 |
| **右前**（右弧线前进）| 正转 | HIGH | LOW | 255 | 停止 | LOW | LOW | 0 |
| **左后**（左弧线后退）| 停止 | LOW | LOW | 0 | 反转 | LOW | HIGH | 255 |
| **右后**（右弧线后退）| 反转 | LOW | HIGH | 255 | 停止 | LOW | LOW | 0 |
| **原地左转** | 反转 | LOW | HIGH | 200 | 正转 | HIGH | LOW | 200 |
| **原地右转** | 正转 | HIGH | LOW | 200 | 反转 | LOW | HIGH | 200 |
| **制动停止** | 制动 | HIGH | HIGH | 0 | 制动 | HIGH | HIGH | 0 |
| **滑行停止** | 惰行 | LOW | LOW | 0 | 惰行 | LOW | LOW | 0 |

> **制动停止 vs 滑行停止**：
> - **制动停止（Brake）**：AIN1=HIGH, AIN2=HIGH，TB6612 内部短接电机绕组，产生反向制动力，电机迅速减速停止
> - **滑行停止（Coast）**：AIN1=LOW, AIN2=LOW，电机自由滑行，靠自身阻力缓慢停止

## 十二、注意事项

| 序号 | 事项 | 说明 |
|:----:|------|------|
| 1 | **3.3V 供电 YFRobot 2015** | YFRobot 2015 必须接 3.3V（非 5V），否则 DAT 输出 5V 可能损坏 ESP32-S3 GPIO |
| 2 | **DAT 上拉电阻** | DAT（GPIO 18）与 YFRobot VCC（3.3V）之间接 10kΩ 上拉电阻，保证空闲时 DAT 维持高电平 |
| 3 | **共地** | 电池组、D153C、ESP32、YFRobot 2015 的 GND 全部短接至公共汇流点 |
| 4 | **STBY 使能** | 若无需动态休眠，可将 STBY 直接接 3.3V 常高，GPIO 10 可释放；正常使用时保持 HIGH |
| 5 | **GPIO 禁用范围** | GPIO 26~32 被 Flash 占用，GPIO 35~37 被 PSRAM 占用，**绝对禁止**用作普通 IO |
| 6 | **电机转向校正** | 若实测某电机转向与预期相反，互换该电机的两根输出线（AO1↔AO2 或 BO1↔BO2），无需修改代码 |
| 7 | **PS2 通信频率** | PS2 软件 SPI 时钟约 250kHz，每次查询约需 5ms，建议控制主循环周期 ≥ 10ms |
| 8 | **蓝牙配对** | YFRobot 2015 解码器与手柄需先完成蓝牙配对；解码器上电后按手柄 PS 键进行配对 |
| 9 | **死区调整** | 代码中的死区阈值（96/160）可根据实际摇杆漂移量调整，建议先串口打印 LX/LY 原始值确认中心偏差 |
| 10 | **电池容量** | 两个 12V 电机在 7.4V 下启动电流可达 2~4A，确认 18650 电池持续放电倍率 ≥ 2C |

## 十三、固件烧录说明（Arduino IDE）

### 13.1 开发环境要求

| 软件 | 版本要求 | 说明 |
|------|:--------:|------|
| **Arduino IDE** | ≥ 2.3 | 推荐使用 IDE 2.x，内置库管理器和串口监视器 |
| **Arduino-ESP32 BSP** | **≥ 3.0**（本固件使用 v3.x API） | 通过 Arduino IDE 的「开发板管理器」安装 |
| **CP210x / CH340 驱动** | 视开发板 USB 芯片而定 | macOS 12+ 需手动安装 CH340 驱动 |

> ⚠️ 本固件（`esp32_robot_controller.ino`）使用 **Arduino-ESP32 v3.x** API（`ledcAttach` / `ledcWrite(pin, val)`）。  
> 若使用 v2.x BSP 编译将报错，请在「开发板管理器」确认版本 ≥ 3.0。

### 13.2 安装 Arduino-ESP32 BSP（v3.x）

1. 打开 Arduino IDE → **文件 → 首选项**
2. 在「附加开发板管理器网址」中添加：
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. 打开 **工具 → 开发板 → 开发板管理器**，搜索 `esp32`
4. 选择 **esp32 by Espressif Systems**，安装 **3.x.x 最新版本**

### 13.3 Arduino IDE 烧录参数配置

打开 `esp32_robot_controller.ino` 后，按下表配置 **工具** 菜单各项：

| 工具菜单项 | 推荐设置 | 说明 |
|-----------|:--------:|------|
| **开发板** | `ESP32S3 Dev Module` | 在 esp32 → ESP32S3 Dev Module |
| **USB CDC On Boot** | `Disabled` | 避免占用 USB 串口影响调试（不使用 USB CDC 输出） |
| **CPU Frequency** | `240MHz (WiFi)` | 最高性能，PS2 软件 SPI 时序更稳定 |
| **Flash Mode** | `QIO 80MHz` | N8R2 8MB Flash 标准模式 |
| **Flash Size** | `8MB (64Mb)` | 对应 N8R2 的 8MB Flash |
| **Partition Scheme** | `8M with spiffs (3MB APP/1.5MB SPIFFS)` | 保证 APP 分区足够大 |
| **PSRAM** | `OPI PSRAM` | N8R2 内置 2MB OPI PSRAM（R2） |
| **Upload Speed** | `921600` | 高速烧录，若失败降为 `460800` |
| **端口** | 对应 USB 串口 | macOS 通常为 `/dev/tty.usbserial-xxxx` 或 `/dev/tty.SLAB_USBtoUART` |

### 13.4 烧录步骤

```
① 用 USB-C 数据线连接 ESP32-S3 N8R2 与电脑
         （确认线材支持数据传输，仅充电线无法识别串口）
② Arduino IDE 选择上述开发板和端口参数
③ 点击「上传（→）」按钮，等待编译完成
④ 若烧录卡在「Connecting...」：
     · 按住 ESP32-S3 板上的 BOOT 按钮
     · 同时短按 RST 按钮后松开
     · 再松开 BOOT 按钮  → 进入下载模式
⑤ 烧录完成后，串口监视器（115200 baud）应显示：
     ========================================
      ESP32-S3 Robot Controller  v1.0
      YFRobot 2015 + TB6612 D153C
     ========================================
     [TB6612] STBY=HIGH, PWM 20kHz 8-bit  OK
     [PS2]   Waiting for YFRobot 2015 decoder......  OK
     [PS2]   Analog mode confirmed (ID=0x73)
     [Ready] Left joystick → motor control
```

### 13.5 常见烧录问题排查

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 端口不显示 | 未安装 USB 转串口驱动 | macOS：安装 CH340 驱动（WCH 官网）或 CP210x 驱动（Silicon Labs） |
| `Connecting...` 超时 | 未进入下载模式 | 按步骤④手动触发 BOOT+RST |
| `ledcAttach was not declared` | BSP 版本为 v2.x | 在开发板管理器升级 esp32 BSP 到 ≥ 3.0 |
| 编译通过但电机不动 | STBY 未拉高 / 接线错误 | 用万用表确认 GPIO 10 高电平；检查 AIN1/AIN2/BIN1/BIN2 接线 |
| PS2 一直 `TIMEOUT` | DAT 无上拉 / VCC 接了 5V | 确认 DAT↔VCC 之间有 10kΩ；确认 YFRobot 2015 接 3.3V |
